# Bioassay Analysis Tool
 
**Status: 🚧 Work in progress**
 
An R Shiny app for the analysis, quality control, and exploration of 384-well plate-based compound screening data acquired on a Tecan SPARK plate reader.
 
## Current Features
 
- Analysis of 384-well plate compound screening data
- Quality control checks and diagnostics
- Interactive data exploration
- Compound Similarity calculation
